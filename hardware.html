Computer Hardware क्या है?

Computer के वे सभी भौतिक भाग जिन्हें हम देख और छू सकते हैं, Hardware कहलाते हैं। जैसे Keyboard, Mouse, Monitor, CPU, Printer आदि।

Hardware के प्रमुख प्रकार

  • Input Devices
  • Output Devices
  • Processing Devices
  • Storage Devices
  • Communication Devices

Input Devices

जिन Devices की सहायता से Computer में Data या Instructions दिए जाते हैं, उन्हें Input Devices कहते हैं।

Keyboard: Text और Numbers लिखने के लिए।
Mouse: Computer में Point, Select और Click करने के लिए।
Scanner: Documents या Photos को Digital रूप में लेने के लिए।
Microphone: आवाज को Computer में Input करने के लिए।
Webcam: Video और Images लेने के लिए।

Output Devices

Computer द्वारा Process किए गए परिणाम को दिखाने या सुनाने वाले Devices को Output Devices कहते हैं।

Monitor: Computer की जानकारी Screen पर दिखाता है।
Printer: Digital जानकारी को Paper पर Print करता है।
Speaker: आवाज सुनाने के लिए।
Projector: Computer की Screen को बड़ी Screen पर दिखाने के लिए।

CPU क्या है?

CPU का पूरा नाम Central Processing Unit है। इसे Computer का मुख्य Processing भाग माना जाता है। यह Instructions को Process करने में महत्वपूर्ण भूमिका निभाता है।

Storage Devices

  • Hard Disk
  • SSD
  • Pen Drive
  • Memory Card
  • CD/DVD

Motherboard क्या है?

Motherboard Computer का एक मुख्य Circuit Board है। इसमें Computer के कई महत्वपूर्ण Components जुड़े होते हैं, जैसे Processor, Memory और अन्य Hardware Components।

RAM क्या है?

RAM का पूरा नाम Random Access Memory है। यह Computer में वर्तमान समय में चल रहे Programs और Data के लिए अस्थायी Memory के रूप में काम करती है।

Hardware और Software में अंतर

Hardware: Computer के वे Parts जिन्हें हम देख और छू सकते हैं।

Software: Computer में चलने वाले Programs और Instructions जिन्हें हम सामान्य रूप से छू नहीं सकते।

Computer Hardware सीखने का लाभ

Hardware की जानकारी से विद्यार्थी Computer के अलग-अलग Parts, उनके कार्य और Computer System की मूल संरचना को बेहतर तरीके से समझ सकते हैं।
