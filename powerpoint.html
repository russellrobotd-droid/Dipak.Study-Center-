Microsoft PowerPoint क्या है?

Microsoft PowerPoint एक Presentation Software है। इसका उपयोग Slides बनाकर किसी विषय की जानकारी को आकर्षक तरीके से प्रस्तुत करने के लिए किया जाता है।

PowerPoint के प्रमुख उपयोग

  • Presentation बनाना
  • Slides तैयार करना
  • Text और Pictures जोड़ना
  • Charts और Tables लगाना
  • Audio और Video जोड़ना
  • Slide Show चलाना
  • शैक्षणिक और Office Presentation बनाना

नई Presentation कैसे बनाएँ?

  1. Microsoft PowerPoint खोलें।
  2. New Presentation चुनें।
  3. Blank Presentation पर क्लिक करें।
  4. अपनी पहली Slide में जानकारी लिखें।
  5. नई Slide जोड़कर आगे की जानकारी लिखें।

Slide क्या है?

PowerPoint Presentation में जानकारी दिखाने वाले प्रत्येक Page को Slide कहा जाता है। एक Presentation में कई Slides हो सकती हैं।

Slide में क्या-क्या जोड़ सकते हैं?

  • Text
  • Pictures
  • Shapes
  • Tables
  • Charts
  • Audio
  • Video

Transition क्या है?

एक Slide से दूसरी Slide पर जाते समय दिखाई देने वाले Effect को Transition कहते हैं।

Animation क्या है?

Slide में मौजूद Text, Picture या अन्य Object पर लगाया गया Movement Effect Animation कहलाता है।

Slide Show कैसे चलाएँ?

  1. PowerPoint Presentation खोलें।
  2. Slide Show Tab पर जाएँ।
  3. From Beginning चुनें।
  4. Presentation Full Screen में दिखाई देगी।

PowerPoint की महत्वपूर्ण Shortcut Keys

Ctrl + N → नई Presentation
Ctrl + S → Save करना
Ctrl + P → Print करना
Ctrl + M → नई Slide
Ctrl + C → Copy
Ctrl + V → Paste
Ctrl + X → Cut
Ctrl + Z → Undo
F5 → Slide Show शुरू करना
Esc → Slide Show बंद करना

PowerPoint सीखने का लाभ

PowerPoint सीखने से विद्यार्थी School Project, College Presentation, Office Presentation और अन्य महत्वपूर्ण कार्यों के लिए अच्छी Presentation बना सकते हैं।
