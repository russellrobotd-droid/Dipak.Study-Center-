Adobe PageMaker क्या है?

Adobe PageMaker एक Desktop Publishing (DTP) Software है। इसका उपयोग Page Layout और विभिन्न प्रकार के Documents तैयार करने के लिए किया जाता था।

PageMaker के प्रमुख उपयोग

  • Page Layout बनाना
  • Books और Magazines का Design
  • Brochure बनाना
  • Newsletter तैयार करना
  • Invitation Card Design
  • Poster और Advertisement तैयार करना
  • Text और Images को व्यवस्थित करना

PageMaker के महत्वपूर्ण Tools

Pointer Tool: Object को Select और Move करने के लिए।
Text Tool: Page पर Text लिखने के लिए।
Line Tool: Line बनाने के लिए।
Rectangle Tool: Rectangle या Box बनाने के लिए।
Ellipse Tool: Circle या Oval बनाने के लिए।
Zoom Tool: Page को बड़ा या छोटा करके देखने के लिए।

नया Document कैसे बनाएँ?

  1. Adobe PageMaker खोलें।
  2. File Menu पर क्लिक करें।
  3. New विकल्प चुनें।
  4. Page Size चुनें।
  5. Margins सेट करें।
  6. OK पर क्लिक करें।

Text कैसे लिखें?

  1. Text Tool चुनें।
  2. Page पर Text Area बनाएँ।
  3. अपना Text लिखें।
  4. Font और Font Size बदलें।
  5. Text को आवश्यकतानुसार Format करें।

Image कैसे लगाएँ?

  1. File Menu खोलें।
  2. Place विकल्प चुनें।
  3. Computer से Image चुनें।
  4. Open पर क्लिक करें।
  5. Image को Page पर सही स्थान पर रखें।

PageMaker में File Save करना

अपने काम को सुरक्षित रखने के लिए File Menu में जाकर Save विकल्प का उपयोग करें। Document को बाद में फिर से खोलकर Edit किया जा सकता है।

DTP क्या है?

DTP का पूरा नाम Desktop Publishing है। Computer की सहायता से Text और Graphics को व्यवस्थित करके Page तैयार करने की प्रक्रिया को Desktop Publishing कहते हैं।

PageMaker सीखने का लाभ

PageMaker की जानकारी से विद्यार्थियों को DTP और Page Layout की बुनियादी समझ मिलती है। इससे वे विभिन्न प्रकार के Printed Documents के Design को समझ सकते हैं।
