Adobe Photoshop क्या है?

Adobe Photoshop एक लोकप्रिय Image Editing और Graphic Design Software है। इसका उपयोग Photos को Edit करने, Images बनाने, रंग और आकार बदलने तथा विभिन्न प्रकार के Graphic Design तैयार करने के लिए किया जाता है।

Photoshop के प्रमुख उपयोग

  • Photo Editing
  • Photo Retouching
  • Image का आकार बदलना
  • Background बदलना
  • Poster और Banner बनाना
  • Logo और Graphic Design बनाना
  • Text और Effects जोड़ना
  • Social Media Graphics बनाना

Photoshop के महत्वपूर्ण Tools

Move Tool: किसी Object या Layer को एक स्थान से दूसरे स्थान पर ले जाने के लिए।
Crop Tool: Image के अनावश्यक हिस्से को हटाने के लिए।
Brush Tool: Image पर Brush से Drawing या Painting करने के लिए।
Eraser Tool: Image के किसी हिस्से को मिटाने के लिए।
Text Tool: Image में Text लिखने के लिए।
Zoom Tool: Image को बड़ा या छोटा करके देखने के लिए।

Layer क्या है?

Photoshop में Layer एक अलग स्तर होता है जिसमें Text, Image या अन्य Design Elements रखे जा सकते हैं। Layers की सहायता से Design को आसानी से Edit किया जा सकता है।

नई Image कैसे बनाएँ?

  1. Adobe Photoshop खोलें।
  2. File → New पर क्लिक करें।
  3. Image की Width और Height चुनें।
  4. Resolution सेट करें।
  5. Create पर क्लिक करें।

Photo कैसे Open करें?

  1. Photoshop खोलें।
  2. File → Open पर क्लिक करें।
  3. अपने Computer से Photo चुनें।
  4. Open पर क्लिक करें।

Photo का Size कैसे बदलें?

  1. Photo को Photoshop में Open करें।
  2. Image Menu पर जाएँ।
  3. Image Size चुनें।
  4. Width और Height बदलें।
  5. OK पर क्लिक करें।

Photoshop में File Save करना

Photoshop Project को Edit करने के लिए PSD Format में Save किया जा सकता है। सामान्य Image के लिए JPEG या PNG जैसे Format का उपयोग किया जा सकता है।

महत्वपूर्ण Shortcut Keys

Ctrl + N → New Document
Ctrl + O → Open
Ctrl + S → Save
Ctrl + C → Copy
Ctrl + V → Paste
Ctrl + Z → Undo
Ctrl + T → Free Transform
C → Crop Tool
B → Brush Tool
E → Eraser Tool
T → Text Tool
V → Move Tool

Photoshop सीखने का लाभ

Photoshop सीखने से विद्यार्थी Photo Editing, Graphic Design, Poster Design, Banner Design और अन्य Creative Computer Work करना सीख सकते हैं।
