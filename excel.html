Microsoft Excel क्या है?

Microsoft Excel एक Spreadsheet Software है। इसका उपयोग Data को व्यवस्थित करने, गणना करने, Table बनाने और Charts तैयार करने के लिए किया जाता है।

Excel के प्रमुख उपयोग

  • Data Entry करना
  • Calculation करना
  • Table बनाना
  • Marksheet बनाना
  • Salary और खर्च का हिसाब रखना
  • Charts बनाना
  • Data को Sort और Filter करना

Row, Column और Cell क्या है?

Row: Excel में बाएँ से दाएँ जाने वाली क्षैतिज लाइन को Row कहते हैं।

Column: Excel में ऊपर से नीचे जाने वाली लंबवत लाइन को Column कहते हैं।

Cell: Row और Column के मिलने से बनने वाले स्थान को Cell कहते हैं।

Excel में Formula क्या है?

Excel में गणना करने के लिए Formula का उपयोग किया जाता है। Formula हमेशा = चिन्ह से शुरू होता है।

=A1+B1
=A1-B1
=A1*B1
=A1/B1

महत्वपूर्ण Excel Functions

=SUM(A1:A10)

कई Numbers का जोड़ निकालने के लिए।

=AVERAGE(A1:A10)

औसत निकालने के लिए।

=MAX(A1:A10)

सबसे बड़ी संख्या पता करने के लिए।

=MIN(A1:A10)

सबसे छोटी संख्या पता करने के लिए।

=COUNT(A1:A10)

Numbers वाले Cells की संख्या गिनने के लिए।

Excel में Table कैसे बनाएँ?

  1. Excel खोलें।
  2. अपना Data लिखें।
  3. पूरे Data को Select करें।
  4. Insert Tab पर जाएँ।
  5. Table विकल्प चुनें।
  6. OK पर क्लिक करें।

Excel में Chart क्या है?

Chart का उपयोग Data को Graphical रूप में दिखाने के लिए किया जाता है। Excel में Column Chart, Bar Chart, Line Chart और Pie Chart जैसे अलग-अलग प्रकार के Charts बनाए जा सकते हैं।

Excel की महत्वपूर्ण Shortcut Keys

Ctrl + N → नया Workbook
Ctrl + O → Workbook खोलना
Ctrl + S → Save करना
Ctrl + P → Print करना
Ctrl + C → Copy
Ctrl + V → Paste
Ctrl + X → Cut
Ctrl + Z → Undo
Ctrl + A → Select All
Ctrl + F → Find

Excel सीखने का लाभ

Microsoft Excel सीखने से विद्यार्थी Data Entry, हिसाब-किताब, Marksheet, Office Work और कई प्रकार के Computer से जुड़े कार्य आसानी से कर सकते हैं।
